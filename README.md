# gitlane

A fast, native branch-graph viewer for Git repositories.

Shows the commit graph the way GitKraken does — one lane per branch, colored
edges, labels on branch tips — and lets you switch branches by clicking the
graph. Nothing else: no staging, no commits, no pull requests.

Built in Rust with `egui`/`eframe` (GPU rendering, no webview) so it stays
small and does not hold hundreds of megabytes of RAM open in the background.
